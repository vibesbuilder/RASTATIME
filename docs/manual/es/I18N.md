# Idiomas (i18n)

> **Dónde está usted en el manual.** Este capítulo cubre
> la función de cambio de idioma visible para cada usuario
> (vía el menú de usuario), más el detalle técnico de
> añadir / actualizar traducciones para el lector
> técnico.

RASTATIME viene con **inglés** y **alemán** incorporados.
Las traducciones francesa y española están presentes pero
parciales (traducidas a máquina, marcadas fuzzy). Cada
etiqueta que los operadores ven en la interfaz web pasa a
través de `gettext` y puede ser traducida.

El idioma puede establecerse:

- **A nivel sistema** — Configuración → Preferencias
  generales → Idioma por defecto.
- **Por usuario** — Menú de usuario → **Idioma** →
  elegir. Guardado con la cuenta de usuario.
- **Por petición** — No soportado directamente.

---

## 1. Cambiar su propio idioma

Menú de usuario arriba a la derecha → **Idioma** →
seleccionar de la lista.

La elección se guarda con su cuenta de usuario en
`cc_subjs`. Cierre sesión e inicie sesión de nuevo (o
refresque la página) para que el cambio surta pleno
efecto — el idioma se carga una vez por sesión al iniciar
sesión.

> **Por qué la página traduce parcialmente?** Los
> templates PHP renderizan en tiempo de petición, así que
> se actualizan inmediatamente. Las cadenas JavaScript
> del lado del cliente se cargan una vez en la carga de
> página y necesitan un refresco completo para
> actualizarse. Vea ARCHITECTURE §20.3.

## 2. Los cuatro idiomas entregados

| Locale | Estado | Notas |
|---|---|---|
| **en_US** | Idioma fuente, 100 % | La referencia. Todas las claves msgid son en_US. |
| **de_DE** | Completa, revisada por operador | La locale alemana primaria del equipo RASTATIME. |
| **fr_FR** | Parcial, traducida a máquina | Auto-traducida desde en_US; marcadores fuzzy. Contribuciones comunitarias bienvenidas. |
| **es_ES** | Parcial, traducida a máquina | Igual que fr_FR. |

Las locales LibreTime originales no-inglés / no-alemán
fueron retiradas en commit 1724246.

## 3. Cómo funcionan las traducciones técnicamente

> **Para el lector técnico.** Los operadores pueden
> saltar.

### gettext en Windows sin msgfmt

RASTATIME corre en Windows, donde la cadena de
herramientas GNU gettext (`msgfmt`) es inconfortable de
instalar. Para evitar forzar a los operadores a instalar,
RASTATIME entrega un **compilador .po → .mo Python puro**
en `scripts/compile_messages.py`.

Para reconstruir los archivos .mo después de modificar un
.po:

```powershell
python scripts/compile_messages.py
```

### Dónde viven los archivos

```
   frontend/legacy/locale/
     en_US/LC_MESSAGES/
       rastatime.po       ← fuente inglesa
       rastatime.mo       ← compilado
     de_DE/LC_MESSAGES/
       rastatime.po       ← traducciones alemanas
       rastatime.mo
     fr_FR/LC_MESSAGES/
       rastatime.po
       rastatime.mo
     es_ES/LC_MESSAGES/
       rastatime.po
       rastatime.mo
   backend/api/locale/
     de/LC_MESSAGES/
       django.po          ← mensajes de error API Django
       django.mo
   frontend/locales/
     en/common.json       ← forma JSON para i18n JS
     de/common.json
```

Tres formatos:
- **`rastatime.po/.mo`** — formato gettext, usado por
  PHP vía `_()` y `gettext()`.
- **`django.po/.mo`** — formato gettext, usado por Django
  para mensajes de error de la API REST.
- **`common.json`** — forma JSON, usada por JavaScript vía
  `$.i18n._()`.

### Añadir una nueva cadena traducible

PHP (la más común):

```php
// Antes
$label = 'Save Changes';

// Después
$label = _('Save Changes');
```

JavaScript:

```js
// Antes
var label = 'Save Changes';

// Después
var label = $.i18n._('Save Changes');
```

Luego extraer la cadena a los archivos `.po`:

```powershell
xgettext --keyword=_ --output=frontend/legacy/locale/en_US/LC_MESSAGES/rastatime.po \
   $(Get-ChildItem frontend/legacy/application -Recurse -Filter *.php)
```

### El patrón de traducción en tiempo de renderizado (T20.3)

Algunas etiquetas — notablemente el menú de navegación
superior — eran traducidas anteriormente en tiempo de
*carga de configuración*. Esto significaba que el worker
fcgid sostenía la cadena renderizada previamente, y un
cambio de idioma no se propagaba. RASTATIME 2026-05-15
(commit 3b4bcb6) movió la traducción del menú al tiempo
de *renderizado*.

## 4. Añadir una nueva locale

> **Para el lector técnico.** Los operadores pueden
> saltar.

Añadir (por ejemplo) italiano:

1. **Elegir un código de locale.** `it_IT` es canónico.
2. **Crear los directorios:**

```powershell
mkdir frontend/legacy/locale/it_IT/LC_MESSAGES
mkdir backend/api/locale/it/LC_MESSAGES
mkdir frontend/locales/it
```

3. **Copiar `en_US/LC_MESSAGES/rastatime.po` como punto
   de partida:**

```powershell
copy frontend/legacy/locale/en_US/LC_MESSAGES/rastatime.po `
     frontend/legacy/locale/it_IT/LC_MESSAGES/rastatime.po
```

4. **Traducir los campos msgstr** en el nuevo archivo
   .po. Abrir en Poedit (Linux/Mac) o PoEditor (web).
   Marcar traducciones inciertas como `#, fuzzy`.

5. **Compilar:** `python scripts/compile_messages.py`

6. **Añadir la locale a
   `application/models/Locale.php`s `getLocales()`**:

```php
'it_IT' => 'Italiano',
```

7. **Opcional: traducir `backend/api/locale/`s
   `django.po`** para mensajes de error API italianos.

8. **Opcional: traducir `frontend/locales/it/common.json`**
   para cadenas JS del lado del cliente.

9. **Probar:** iniciar sesión, cambiar idioma, recorrer
   cada página.

## 5. Modificar traducciones existentes

El camino más simple:

```powershell
notepad frontend/legacy/locale/de_DE/LC_MESSAGES/rastatime.po
```

Encuentre la msgid que quiere corregir, cambie su msgstr,
guarde. Recompile:

```powershell
python scripts/compile_messages.py
```

Refresco del navegador → traducción actualizada visible.

### Primer del formato de archivo PO

```
msgid "Save Changes"
msgstr "Guardar cambios"

msgid "Cancel"
msgstr "Cancelar"

#, fuzzy
msgid "Sometimes uncertain string"
msgstr "A veces cadena incierta"
```

- `msgid` — la cadena fuente inglesa (inmutable).
- `msgstr` — la cadena traducida.
- `#, fuzzy` — comentario marcando la traducción como
  incierta.

### Formas plurales

```
msgid "1 track"
msgid_plural "%d tracks"
msgstr[0] "1 pista"
msgstr[1] "%d pistas"
```

Otros idiomas pueden tener más formas (ej. ruso tiene 3).

## 6. Formato de fecha y número

Estos formatos **no** son controlados por el ajuste de
idioma RASTATIME. Siguen la **locale del navegador**
(`navigator.language` en JS) para renderizado del lado
del cliente, y la **zona horaria del operador** para
renderizado del lado del servidor.

Para obtener formato de fecha español ("21/05/2026" en
lugar de "05/21/2026"):

- Establezca el idioma de su navegador a es-ES (en los
  ajustes de su OS).
- Las cadenas UI de RASTATIME pueden quedarse en inglés;
  solo las fechas cambian.

> **Por qué separado así?** Un usuario que trabaja en
> texto inglés pero prefiere el formato de fecha ISO
> ("2026-05-21") no debería tener que cambiar toda la UI
> a español solo por la fecha.

## 7. Preguntas frecuentes

### "Cambié el idioma pero algunas cadenas siguen en inglés."

Causas:
- La cadena en la fuente PHP no está envuelta en `_()`.
  Reportar un bug.
- El archivo `.po` tiene la msgstr vacía para esa msgid.
- Su navegador cacheó las cadenas JS. Refresco duro
  (Ctrl+Shift+R).

### "La página de inicio de sesión 'admin' está en el idioma equivocado."

La página de inicio de sesión usa el **idioma por
defecto del sistema** (Preferencias generales → Idioma
por defecto) porque aún no existe sesión de usuario.

### "¿Puedo tener programas en un idioma y la interfaz en otro?"

Sí. Nombres de programas, descripciones, nombres de
presentadores son entradas de usuario arbitrarias.

### "¿Por qué la API Django responde en inglés cuando mi interfaz está en español?"

La API Django tiene su propio conjunto de traducciones
(`backend/api/locale/`) que puede ser incompleto para el
idioma. Actualmente solo los errores de API alemanes
están traducidos.

### "¿Cómo contribuyo una traducción al upstream?"

Abra un pull request contra el repositorio RASTATIME con
los archivos `.po` actualizados. Vea
[`CONTRIBUTING.md`](../../../CONTRIBUTING.md) para el
workflow PR completo.

### "¿Puedo traducir a máquina como punto de partida?"

Sí — así es como francés y español funcionan actualmente.
Ejecute el .po a través de DeepL, Google Translate, o un
modelo de traducción local, marque cada cadena traducida
a máquina como `#, fuzzy`, y limpie a mano.

### "¿Qué hay de los idiomas RTL (árabe, hebreo)?"

La UI fue diseñada de izquierda a derecha. Añadir un
idioma RTL requeriría retrabajo CSS además de la
traducción. No está en el alcance actualmente.
