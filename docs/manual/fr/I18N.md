# Langues (i18n)

> **Où vous êtes dans le manuel.** Ce chapitre couvre la
> fonctionnalité de changement de langue visible à chaque
> utilisateur (via le menu utilisateur), plus le détail
> technique de l'ajout / mise à jour des traductions pour
> le lecteur technique.

RASTATIME est livré avec **anglais** et **allemand**
intégrés. Les traductions française et espagnole sont
présentes mais partielles (machine-traduites, marquées
fuzzy). Chaque libellé que les opérateurs voient dans
l'interface web passe par `gettext` et peut être traduit.

La langue peut être définie :

- **Au niveau système** — Paramètres → Préférences
  générales → Langue par défaut.
- **Par utilisateur** — Menu utilisateur → **Langue** →
  choisir. Enregistrée avec le compte utilisateur.
- **Par requête** — Pas directement supporté.

---

## 1. Changer sa propre langue

Menu utilisateur en haut à droite → **Langue** →
sélectionner dans la liste.

La choix est enregistrée avec votre compte utilisateur
dans `cc_subjs`. Déconnectez-vous et reconnectez-vous (ou
rafraîchissez la page) pour que le changement prenne
pleinement effet — la langue est chargée une fois par
session à la connexion.

> **Pourquoi la page traduit-elle partiellement ?** Les
> templates PHP rendent au moment de la requête, donc ils
> se mettent à jour immédiatement. Les chaînes
> JavaScript côté client sont chargées une fois au
> chargement de page et nécessitent un rafraîchissement
> complet pour se mettre à jour. Voir ARCHITECTURE §20.3.

## 2. Les quatre langues livrées

| Locale | Statut | Notes |
|---|---|---|
| **en_US** | Langue source, 100 % | La référence. Toutes les clés msgid sont en_US. |
| **de_DE** | Complète, révisée par opérateur | La locale allemande principale de l'équipe RASTATIME. |
| **fr_FR** | Partielle, machine-traduite | Auto-traduite depuis en_US ; marqueurs fuzzy. Contributions communautaires bienvenues. |
| **es_ES** | Partielle, machine-traduite | Comme fr_FR. |

Les locales LibreTime d'origine non-anglais / non-allemand
ont été retirées dans le commit 1724246.

## 3. Comment les traductions fonctionnent techniquement

> **Pour le lecteur technique.** Les opérateurs peuvent
> sauter.

### gettext sous Windows sans msgfmt

RASTATIME tourne sous Windows, où la chaîne d'outils GNU
gettext (`msgfmt`) est inconfortable à installer. Pour
éviter de forcer les opérateurs à installer, RASTATIME
livre un **compilateur .po → .mo Python pur** à
`scripts/compile_messages.py`.

Pour reconstruire les fichiers .mo après modification
d'un .po :

```powershell
python scripts/compile_messages.py
```

### Où vivent les fichiers

```
   frontend/legacy/locale/
     en_US/LC_MESSAGES/
       libretime.po       ← source anglaise
       libretime.mo       ← compilé
     de_DE/LC_MESSAGES/
       libretime.po       ← traductions allemandes
       libretime.mo
     fr_FR/LC_MESSAGES/
       libretime.po
       libretime.mo
     es_ES/LC_MESSAGES/
       libretime.po
       libretime.mo
   backend/api/locale/
     de/LC_MESSAGES/
       django.po          ← messages d'erreur API Django
       django.mo
   frontend/locales/
     en/common.json       ← forme JSON pour i18n JS
     de/common.json
```

Trois formats :
- **`libretime.po/.mo`** — format gettext, utilisé par
  PHP via `_()` et `gettext()`.
- **`django.po/.mo`** — format gettext, utilisé par
  Django pour les messages d'erreur de l'API REST.
- **`common.json`** — forme JSON, utilisée par JavaScript
  via `$.i18n._()`.

### Ajouter une nouvelle chaîne traduisible

PHP (le plus courant) :

```php
// Avant
$label = 'Save Changes';

// Après
$label = _('Save Changes');
```

JavaScript :

```js
// Avant
var label = 'Save Changes';

// Après
var label = $.i18n._('Save Changes');
```

Puis extraire la chaîne dans les fichiers `.po` :

```powershell
xgettext --keyword=_ --output=frontend/legacy/locale/en_US/LC_MESSAGES/libretime.po \
   $(Get-ChildItem frontend/legacy/application -Recurse -Filter *.php)
```

### Le motif de traduction à l'heure de rendu (T20.3)

Certains libellés — notamment le menu de navigation
supérieur — étaient auparavant traduits au moment de
*chargement de configuration*. Cela signifiait que le
worker fcgid tenait la chaîne précédemment rendue, et un
changement de langue ne propageait pas. RASTATIME
2026-05-15 (commit 3b4bcb6) a déplacé la traduction du
menu vers l'heure de *rendu*.

## 4. Ajouter une nouvelle locale

> **Pour le lecteur technique.** Les opérateurs peuvent
> sauter.

Ajouter (par exemple) l'italien :

1. **Choisir un code de locale.** `it_IT` est canonique.
2. **Créer les répertoires :**

```powershell
mkdir frontend/legacy/locale/it_IT/LC_MESSAGES
mkdir backend/api/locale/it/LC_MESSAGES
mkdir frontend/locales/it
```

3. **Copier `en_US/LC_MESSAGES/libretime.po` comme point
   de départ :**

```powershell
copy frontend/legacy/locale/en_US/LC_MESSAGES/libretime.po `
     frontend/legacy/locale/it_IT/LC_MESSAGES/libretime.po
```

4. **Traduire les champs msgstr** dans le nouveau fichier
   .po. Ouvrir dans Poedit (Linux/Mac) ou PoEditor (web).
   Marquer les traductions incertaines comme `#, fuzzy`.

5. **Compiler :** `python scripts/compile_messages.py`

6. **Ajouter la locale à `application/models/Locale.php`s
   `getLocales()`** :

```php
'it_IT' => 'Italiano',
```

7. **Optionnel : traduire `backend/api/locale/`s
   `django.po`** pour messages d'erreur API italiens.

8. **Optionnel : traduire `frontend/locales/it/common.json`**
   pour chaînes JS côté client.

9. **Tester :** se connecter, changer de langue,
   parcourir chaque page.

## 5. Modifier les traductions existantes

Le chemin le plus simple :

```powershell
notepad frontend/legacy/locale/de_DE/LC_MESSAGES/libretime.po
```

Trouvez la msgid que vous voulez corriger, changez sa
msgstr, enregistrez. Recompilez :

```powershell
python scripts/compile_messages.py
```

Rafraîchissement navigateur → traduction mise à jour
visible.

### Primer du format de fichier PO

```
msgid "Save Changes"
msgstr "Enregistrer les modifications"

msgid "Cancel"
msgstr "Annuler"

#, fuzzy
msgid "Sometimes uncertain string"
msgstr "Parfois chaîne incertaine"
```

- `msgid` — la chaîne source anglaise (immuable).
- `msgstr` — la chaîne traduite.
- `#, fuzzy` — commentaire marquant la traduction comme
  incertaine.

### Formes plurielles

```
msgid "1 track"
msgid_plural "%d tracks"
msgstr[0] "1 piste"
msgstr[1] "%d pistes"
```

D'autres langues peuvent avoir plus de formes (ex. le
russe en a 3).

## 6. Formatage de date et de nombre

Ces formats ne sont **pas** contrôlés par le paramètre de
langue RASTATIME. Ils suivent la **locale du navigateur**
(`navigator.language` en JS) pour le rendu côté client, et
le **fuseau horaire opérateur** pour le rendu côté
serveur.

Pour obtenir le format de date français ("21/05/2026" au
lieu de "05/21/2026") :

- Définissez la langue de votre navigateur sur fr-FR (dans
  les paramètres de votre OS).
- Les chaînes UI de RASTATIME peuvent rester en anglais ;
  seules les dates changent.

> **Pourquoi séparé ainsi ?** Un utilisateur qui
> travaille en texte anglais mais préfère le format de
> date ISO ("2026-05-21") ne devrait pas avoir à basculer
> toute l'UI en français juste pour la date.

## 7. Foire aux questions

### "J'ai changé la langue mais certaines chaînes sont encore en anglais."

Causes :
- La chaîne dans la source PHP n'est pas enveloppée dans
  `_()`. Signaler un bug.
- Le fichier `.po` a la msgstr vide pour cette msgid.
- Votre navigateur a caché les chaînes JS.
  Rafraîchissement dur (Ctrl+Shift+R).

### "La page de connexion 'admin' est dans la mauvaise langue."

La page de connexion utilise la **langue par défaut
système** (Préférences générales → Langue par défaut)
parce qu'aucune session utilisateur n'existe encore.

### "Puis-je avoir des émissions dans une langue et l'interface dans une autre ?"

Oui. Les noms d'émissions, descriptions, noms
d'animateurs sont des entrées utilisateur arbitraires.

### "Pourquoi l'API Django répond-elle en anglais quand mon interface est en français ?"

L'API Django a son propre jeu de traductions
(`backend/api/locale/`) qui peut être incomplet pour la
langue. Actuellement seules les erreurs API allemandes
sont traduites.

### "Comment contribuer une traduction au upstream ?"

Ouvrez une pull request contre le dépôt RASTATIME avec
les fichiers `.po` mis à jour. Voir
[`CONTRIBUTING.md`](../../../CONTRIBUTING.md) pour le
workflow PR complet.

### "Puis-je machine-traduire comme point de départ ?"

Oui — c'est ainsi que le français et l'espagnol
fonctionnent actuellement. Exécutez le .po à travers
DeepL, Google Translate, ou un modèle de traduction
local, marquez chaque chaîne machine-traduite comme
`#, fuzzy`, et nettoyez à la main.

### "Qu'en est-il des langues RTL (arabe, hébreu) ?"

L'interface a été conçue de gauche à droite. Ajouter une
langue RTL nécessiterait du retravail CSS en plus de la
traduction. Pas dans le champ actuellement.
