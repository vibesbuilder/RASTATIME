## RASTATIME v1.0.0 - first release (2026-11-02)

RASTATIME is a Windows-native radio automation system derived from
LibreTime 4.5.0 (AGPL-3.0): the same scheduling and library model,
rebuilt around Liquidsoap 2.4 on Windows, NSSM services, Apache +
PHP 8.5, PostgreSQL 17 and RabbitMQ.  It has run the 24/7 programme of
a community station since 2026-10-03.

### What is in 1.0.0

- **Playout on Liquidsoap 2.4.6 (Windows build).**  Scheduled tracks,
  web streams and line-in sources on one internal bus with gates, track
  and show crossfades, cue points, EBU R128 loudness (stage 1), optional
  Stereo Tool processing, ICY metadata and a Live Text feed.  DJ harbors
  with logins checked against the web application.
- **Planned restarts without listener loss.**  Nightly window, memory
  thresholds and settings changes restart the engine at a track boundary;
  a standby Liquidsoap keeps the Icecast fallback mounts fed; the running
  item is caught up at its offset after any restart.
- **Operator UI.**  Calendar with undo, show repeats, autoloading with
  exact fill, teasers, failed-upload handling, import format
  normalisation, re-read tags, library-wide cue-point detection,
  import/export bundles, backup and restore from the Settings pages,
  widgets in the station's default language.
- **Operations.**  Eight NSSM services, `status.ps1`, `bootstrap.ps1`,
  crash recovery and restart-order runbooks, HTTPS go-live guide, a test
  plan and a fresh-machine install rehearsal protocol.
- **Security.**  bcrypt password hashes, CSRF protection, login
  brute-force brake, loopback binds for database, broker and API, DJ
  authentication only from the local machine.

### Installing

Follow `docs/operator/INSTALL.md` (Windows 11, about 2-4 hours; the
rehearsal on a fresh VM took 5 hours including documentation fixes).
`INSTALL_APACHE.md` covers Apache + PHP, `INSTALL_PROBE.md` is the
rehearsal protocol.  The frontend zip attached to this release already
contains the Composer `vendor` folder.

### Upgrading

There is no earlier release; `docs/operator/UPGRADE.md` describes the
procedure for the releases to come.

### Known limitations

- Windows only; Linux coupling of the upstream project was removed, not
  ported.
- `RASTATIME-WORKER` is a placeholder service without jobs.
- The user manual (English, German, French, Spanish) is complete for the
  operator-facing pages; some screenshots are text mock-ups.

The full change history since the fork (April 2026) is in
`CHANGELOG.md` (German).
