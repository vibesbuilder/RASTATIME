## RASTATIME v1.4.0 (2026-11-11)

A release on top of 1.3.0. It adds track availability dates and a country per track with
a music-by-country report, a category per show, a Radioplayer now-playing feed, delays for
the now-playing outputs, more widget settings, and reliable stream titles at transitions.
It contains **three database migrations** (0080–0082).

### Added

- **Track availability.**
  - **Track disabled** can be ticked by hand in Edit Track and set in bulk edit. An expiry
    date that has been reached still disables the track.
  - New field **Enabled From**: the track stays disabled until 00:00 on that date.
  - Smart blocks judge availability at the airtime of the row, not when the block is built.
    A show at 00:07 on the enable date gets the track; a show on the expiry date does not.
  - Migration 0080 stores the hand-ticked flag separately (`cc_files.disabled_by_hand`).
- **Country per track and Analytics → Music by Country.**
  - **Country** field in Edit Track and bulk edit, with suggestions. It is also a hidden,
    searchable library column and a smart block criterion. Migration 0081.
  - The report shows plays and minutes of music per country, with shares, a monthly table
    and the most played music tracks without a country. CSV export with country × month.
  - `manage.py backfill_country` fills empty countries once from the files' COUNTRY tag.
- **Tags read on import.**
  - Expiry date, enable date and country are taken from the file tags.
  - The track type is taken from the "Media Type" tag (ID3 `TMED`, `MEDIATYPE` / `MEDIA`)
    when it names a visible track type by code or name.
  - **Re-read Tags** also takes over the country and a known track type.
- **Category per show and Programme Minutes by genre / category.**
  - New free-text field **Category** in Edit Show → What, with suggestions from the values
    already in use. The genre now offers suggestions too.
  - Analytics → Programme Minutes groups the minutes by genre, by category or by both, with
    a CSV export.
  - Show templates and import / export carry the category. Migration 0082.
- **Radioplayer events feed.**
  - `GET /embed/radioplayer-events` returns now-playing data in the Radioplayer v4 "events"
    format: previous, now and next, with covers.
  - It is meant for distribution partners whose players have no Radioplayer integration.
  - Its own settings section (Settings → General → Radioplayer Feed): switch, optional
    access key, rpId, service description, number of entries, short-track threshold, poll
    interval.
- **Delay for Live Text Info and the Radioplayer feed.**
  - Listeners hear the audio a few seconds after the title information.
  - The new **Delay (s)** setting (0–60, default 0) holds the Live Text file and the feed
    back so they change when the listener hears the change.
- **Widget settings for Next/Latest Shows.**
  - Show or hide the heading, font size, text colour, background colour, bold text and font.
  - Archivo is served locally, so the widget requests no font CDN.
  - Each setting can be overridden per embed with a URL parameter.
- **Stereo Tool preset "16 LUFS clean."** The `-23 LUFS` programme leaves the studio at
  `-16 LUFS` / `-1 dBTP`, without AGC or compression.

### Changed

- **Calendar context menu.**
  - Teasers, Archive Online and the new **People Involved** dialog (the guests of an
    episode) sit in an **Extras** submenu below Clear Show.
  - Guests involved is no longer part of Archive Online.
- **"Episode" instead of "Instance"** in the interface and the manual. The Edit and Delete
  submenus now list Edit Episode before Edit Show.
- **Analytics menu order:** Playout History, History Templates, Listener Stats, Show
  Listener Stats, Music by Country, Programme Minutes, People Involved, Archive Status.
- **Settings for Live Text Info and the Radioplayer feed** explain their fields in tooltips.
  The FTP fields of Live Text appear only while the FTP push is switched on.

### Fixed

- **Stream titles at transitions.**
  - The first track after a webstream or line-in now always gets its stream title.
  - A starting webstream no longer shows the off-air text.
  - A guard re-inserts a title whose metadata did not reach the output.
- **Live Text after a Liquidsoap restart.** Live Text switched itself off until the next
  PLAYOUT restart. It is now switched on again with the other stream values.
- **Widgets on the station website.**
  - `/embed/` sends `Content-Security-Policy: frame-ancestors` for the sites listed in
    `RT_EMBED_ANCESTORS` instead of `X-Frame-Options: SAMEORIGIN`.
  - The server renders the date and time of Next/Latest Shows, so they also show in a
    sandboxed iframe. The date format is selectable.
  - Track History scrolls inside its iframe, and its "Load more" text is configurable.
- **Library:**
  - The column chooser and the default sort point at the right columns again.
  - Edit Track closes only after a successful save, and a refusal names its reasons.
- **Import folder:** files with a modification date in the future are no longer left
  waiting until that date.

### Upgrading from 1.3.0

Follow `docs/operator/UPGRADE.md`. In short:

1. Make a backup (*Settings → Backup*).
2. Stop the RASTATIME services. The running analyzer locks its executable, so a reinstall
   with the services running fails halfway.
3. Update the checkout and reinstall the five backend packages (`pip install -e`) so the
   services report 1.4.0.
4. Run `php composer.phar dump-autoload` in `frontend\legacy`. The release has new classes
   for the Radioplayer settings and the widget date format.
5. Apply the migrations with `python rastatime_api\manage.py migrate` (0080 hand-disabled
   flag, 0081 country, 0082 show category).
   - Optional: `manage.py backfill_country` takes the country from the files' tags.
6. Start the services in order (`docs/operator/RESTART_ORDER.md`):
   - PLAYOUT renders a new Liquidsoap script (transition order and metadata guard), so
     `RASTATIME-LIQUIDSOAP` restarts as well. Do not restart it by hand on top.
   - Restart the analyzer so it reads the new tags.
   - Restart Apache so it loads the new translations.
7. Optional, for widgets on another site: set `RT_EMBED_ANCESTORS` in
   `config/apache-site.conf` (see `docs/manual/WIDGETS.md` § 13) and restart Apache.

### Known limitations

- Windows only.
- `RASTATIME-WORKER` runs from the source tree. It has no wheel among the release files.
- With the "16 LUFS clean" preset the stream is no longer EBU R128 compliant. A
  distribution partner that needs R128 needs its own mount.

The full change history is in `CHANGELOG.md` (German).
